## README for Agents

This repository contains sample code for the talk on building data exploration agents using OpenAI Agent SDK. It contains 3 parts:
- Demo code to show Responses API and intro to OpenAI agents in `notebooks` directory
- Sample app to show agentic loop and image drawing in `apps`
- An idea file in `ideas/text-shell.md` what is used to build agentic TUI shell from scratch using coding agent
- A bunch of agents in `agents` directory, that should work with the agentic shell built using idea file above, or sample implementation `ma` (https://github.com/shwars/ma)

ALL the code in this repo is educational, so it should be kept as simple and clear as possible.
